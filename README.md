# Enzimas en Cadena

Juego interactivo para aprender, paso por paso, cuatro rutas metabólicas:

- Glucólisis
- Ciclo de Krebs (con el paso de la piruvato deshidrogenasa)
- Ciclo de la urea
- Glucogenólisis

Se completan las enzimas o los metabolitos de cada ruta. Al acertar, se abre una ficha con lo que hace la enzima, su regulación y un dato para recordar.

El contenido está basado en Marks, *Bioquímica médica*, 5.ª ed. (caps. 22, 23, 26 y 36).

Es un solo archivo estático (`index.html`), sin paso de compilación.
